# Car Rental Management System

## About the Project
The Car Rental Management System is a Java-based application designed to simplify and manage vehicle rental operations. The application provides an organized way to maintain customer records, manage vehicle details, handle bookings and cancellations, and generate revenue reports.

## Key Features
- **Customer Management:** Add, view, and manage customer information.
- **Car Management:** Add and delete vehicle records.
- **Booking Management:** Manage customer vehicle bookings.
- **Booking Cancellation:** Cancel existing bookings.
- **Revenue Reports:** Generate reports of rental revenue.
- **Customer Spending:** Track customer spending details.
- **Booking History:** View individual customer booking records.
- **Database Connectivity:** Store and manage application data using a database.

## Technologies Used
- Java
- MySQL
- JDBC
- SQL

## Project Structure
The project contains Java classes organized under the `com.example.car_rental` package.

## How to Run the Project
1. Clone or download this repository.
2. Open the project in a Java IDE.
3. Configure the database connection details in `DBConnection.java`.
4. Create the required database and tables using the SQL script.
5. Run the main application class.

## Project Purpose
This project demonstrates the practical application of Java programming, object-oriented concepts, database connectivity, and basic database management in a real-world car rental system.
